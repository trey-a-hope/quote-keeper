# Quote Keeper

A Flutter app for readers who want to save the lines that stick with them. Search for a book, attach a quote and a photo to it, and Quote Keeper keeps your collection in the cloud with a dashboard of how many quotes you've saved this week, month, year and all time.

## Features

- **Sign in** with email (`flutter_login`), Google or Apple.
- **Find the book**: search Google Books by title and pick the right edition (`lib/presentation/screens/search_books_screen.dart`).
- **Save a quote**: create or edit a quote for a book, optionally with an image (picked and cropped with `image_picker` / `image_cropper`, stored in Firebase Storage).
- **Your quotes**: a paginated, searchable list of everything you've saved; quote search is powered by Algolia.
- **Dashboard**: a featured quote, your most recent quotes, and counts for this week, month, year and all time.
- **Share** a quote with `share_plus`.
- **Profile and settings**: edit your profile, view stats, send feedback (`feedback` package), read the About page, and delete your account along with all your books.
- **Push notifications** through Firebase Cloud Messaging and local notifications; crash reporting with Crashlytics.

## How it works

The app follows a data / domain / presentation split with Riverpod for state and `go_router` for navigation (`lib/utils/config/app_routes.dart`). Signed-in users land in `NavigationContainer`, a bottom bar with Dashboard, Quotes and Profile tabs; search, create/edit quote, edit profile, settings and about are pushed routes.

- `lib/data/services/` talks to Firebase (Firestore `books` and `users` collections, Storage, FCM) and the Google Books API (`BookService.searchGoogleBooks`).
- `lib/domain/notifiers/` holds Riverpod notifiers for auth, the user, books, dashboard counts and searches; `lib/domain/models/` holds Freezed/json_serializable models.
- `lib/presentation/` has the screens and widgets.

```
lib/
├── main.dart, navigation_container.dart, firebase_options.dart
├── data/          # services (book, user, storage, FCM, share, feedback), cache
├── domain/        # models, notifiers, repositories
├── presentation/  # screens, widgets (dashboard, profile, quote cards)
└── utils/         # routes, providers, themes, constants, extensions, converters
```

## Getting started

### Prerequisites

- Flutter SDK (Dart 3)
- A Firebase project with Auth (email, Google, Apple), Firestore, Storage and Cloud Messaging enabled. `lib/firebase_options.dart` and `firebase.json` are generated by the FlutterFire CLI; run `flutterfire configure` to point the app at your own project.
- A Google Books API key and an Algolia app with a `books` index. These are read from `lib/utils/constants/globals.dart`.

### Run

```sh
flutter pub get
dart run build_runner build --delete-conflicting-outputs   # Freezed / JSON models
flutter run
```
